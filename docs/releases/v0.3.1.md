# DVM Console 0.3.1

Prepared 2026-08-19. This patch release improves received DMR, NXDN, and P25 Phase 2 presentation loudness, adds an operator-controlled LMR receiver-style enhancement stage, and fixes intermittent DMR receive dropouts.

## Added

- Add a small, default-on **RX audio processing** checkbox below the master output-device selector.

## Changed

- Persist the RX processing choice and safely rebuild active listening and patch-source decode sessions when it changes.
- Aggregate RX and TX vocoder level diagnostics over full 8,000-sample windows instead of sampling one arbitrary 20 ms vocoder frame.

## Fixed

- Distinguish the DMR network frame-type bits from the embedded voice-burst sequence so burst 2 cannot be misclassified as a privacy-indicator header and lose all three of its 20 ms voice frames.

## Packages

- `dvmconsole-0.3.1-osx-arm64.zip` — Apple Silicon macOS application bundle.
- `dvmconsole-0.3.1-osx-x64.zip` — Intel macOS application bundle.
- `dvmconsole-0.3.1-win-x64.zip` — Windows x64 package containing the self-contained `DvmConsole.exe`.

## Safety and compatibility

DVMHost/FNE R06A00 or newer is recommended. This software is for personal, non-commercial, amateur, and educational use and must not be used in public-safety or life-safety-critical applications.
