# DVM Console 0.1.0

Released 2026-08-16. This is the first public release of the cross-platform Avalonia DVM Console, with self-contained packages for Apple Silicon macOS, Intel macOS, and Windows x64 while retaining the established DVM FNE and codeplug workflow.

## Added

- Monitor and transmit on multiple configured DVM FNE systems, with visible connection state, independent RX, TX, PAGE, ALERT, and TAR controls, and indexed live-traffic routing.
- Keep dense, mixed-size layouts responsive with bounded small-card audio meters.
- Decode and encode P25 and DMR audio through the [dvmvocoder](https://github.com/DVMProject/dvmvocoder/tree/main) library, with simultaneous receive mixing, per-channel volume, and output-device overrides.
- Use card PTT, application/global keyboard PTT, or an optional serial PTT device.
- Use DVM Console microphone processing on macOS and Windows, or Apple Voice Processing I/O with echo cancellation and AGC on compatible macOS routes.
- Send built-in alerts, custom alert audio, DTMF, generated tones, and QCII pages to armed resources.
- Use local and KMM-provided P25 encryption keys while preserving compatibility with existing variable-length AES key material.
- Configure patches, multi-select groups, call history, recordings, web streams, clocks, layouts, themes, and startup behavior from Console Settings.
- Dismiss codeplug diagnostics after reviewing warnings and read the current operator documentation inside the application.

## Packages

- `dvmconsole-0.1.0-osx-arm64.zip` — Apple Silicon macOS application bundle.
- `dvmconsole-0.1.0-osx-x64.zip` — Intel macOS application bundle.
- `dvmconsole-0.1.0-win-x64.zip` — Windows x64 single-file application and vocoder.

The packages are self-contained; a separate .NET installation is not required. Both macOS packages require macOS 14 or newer. All builds are currently unsigned.

### macOS installation

Move `DVMConsole.app` to Applications, then remove the quarantine attribute from the official downloaded release:

```sh
xattr -dr com.apple.quarantine "/Applications/DVMConsole.app"
```

macOS may request local-network, microphone, Accessibility, or Input Monitoring permission as the corresponding features are first used.

### Windows installation

Extract the complete ZIP and start `DvmConsole.Desktop.exe` for the 0.1.0 package. Releases after 0.1.1 use `DvmConsole.exe`. Keep `libvocoder.dll` beside the EXE. Microsoft Defender SmartScreen may warn because the application is unsigned.

## Compatibility and limitations

- DVMHost/FNE R06A00 or newer is recommended. Older FNE builds may behave unpredictably.
- Codeplugs created for the original R01A00 console should be reviewed before use because resource configuration has changed substantially.
- Apple voice processing on macOS requires the system-default input/output pair or one duplex Core Audio device. Use DVM Console processing for unrelated split input/output devices.
- Subscriber acknowledgement decoding for P25 commands is not yet implemented.
- Intel macOS and Windows hardware audio and global-hotkey behavior should be validated on the intended operator workstation.
