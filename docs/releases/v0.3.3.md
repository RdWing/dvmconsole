# DVM Console 0.3.3

Prepared 2026-08-21. This patch release adds adaptive per-FNE receive jitter buffering and scoped live-output mute controls, improves receive diagnostics and operator layouts, strengthens delayed KMM key handling, and fixes Debug Logs and saved tone-pattern reliability.

## Added

- Add independent P25, DMR, and NXDN packet-aligned jitter buffers for each FNE connection, with fixed modes and a default adaptive mode that learns from zero through nine protocol frames while keeping every receive stream on a call-stable playout clock.
- Add live speaker-output mute controls for all RX, the selected system, and the selected zone. Decode, call state, patching, and TAR recording continue while any speaker scope is muted.

## Changed

- Decode complete RX network packets into caller-owned PCM batches before continuing through the receive chain, reducing scheduler and allocation pressure without changing established gain, smoothing, or optional processing.
- Shorten receive cleanup to one second of inactivity plus one second of grace, with a two-second post-terminator hold, and report restored packet order separately from missed jitter deadlines.
- Show Activity Event History for RX-enabled channels by default, with independent `Active`/`All` and `Zone Wide`/`System Wide` filters.
- Restore the main console's last reachable normal size and position at launch.
- Replace rapidly changing packet details with readable connection-session totals, bounded current-stream summaries, coalesced health updates, and a current-session-only 100 MB Debug Logs limit.
- Keep responsive per-FNE jitter controls beside a state-aware Connect/Disconnect action, apply selections immediately, and show learned adaptive targets and reorder/deadline effectiveness counters.

## Fixed

- Age overflowing live RX lanes only at whole-packet boundaries, preserve the complete TAR timeline, detect stalled physical output callbacks on macOS and Windows, and expose separate FNE, decoder, mixer, and device timing evidence.
- Keep three complete P25 LDUs of live-lane headroom and make RX meters follow the selected receive stream while UI lifecycle work catches up.
- Finalize TAR Ogg Opus recordings with the exact PCM-duration end timestamp instead of advertising codec-frame padding.
- Interpret unprefixed P25 key IDs as hexadecimal and pace post-connect FNE/KMM key requests with legacy-compatible settling and spacing.
- Refresh selectable-encryption controls when a delayed KMM-derived key arrives so a restored secure channel presents `SECURE` as soon as its matching key becomes available.
- Reflow FNE connection identity, jitter controls, connection actions, microphone processing values, and AGC controls when Console Settings is narrowed.
- Keep Debug Logs responsive during busy traffic with incremental virtualization, compact rows, stable reading position as new entries arrive, and safe recycled-row handling.
- Preserve saved Alert/QCII tone-pattern steps shorter than 0.25 seconds instead of raising them to the former preset floor.

## Safety and compatibility

DVMHost/FNE R06A00 or newer is recommended. This software is for personal, non-commercial, amateur, and educational use and must not be used in public-safety or life-safety-critical applications.

The current FNE plaintext and legacy encrypted transports are compatibility protocols, not mutually authenticated sessions. Use FNE only across a trusted network or an authenticated VPN.
