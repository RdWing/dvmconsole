# DVM Console NEO 0.6.1

Version 0.6.1 is a small hotfix for the compact List workspace. It also expands
the bundled network-disabled demo.

## Hotfixes

- Restore List control colors and PTT input, including hold, toggle, and
  keyboard Space operation. Expanded rows also stay in place while their detail
  panel opens or closes.
- Save the exact main-window size and position before Quit completes.
- Provide a larger multi-zone workspace in the network-disabled demo.

## Packages

Extract the complete archive before starting DVM Console NEO.

| Platform | Package |
| --- | --- |
| Apple Silicon macOS | `dvmconsole-0.6.1-osx-arm64.zip` |
| Intel macOS | `dvmconsole-0.6.1-osx-x64.zip` |
| Windows x64 | `dvmconsole-0.6.1-win-x64.zip` |

The packages are unsigned and not notarized. Signing and notarization status is
reported with the release.

## Safety and compatibility

- FNE packet formats, vocoder payloads, transmit pacing, encryption signaling,
  and codeplug structure are unchanged.
- Existing 0.6.0 managed configurations and operator settings do not require
  migration.
- The expanded demo is network-disabled and does not contain operational system
  data.
- Live FNE, radio, microphone, speaker, Bluetooth, serial PTT, and Windows
  hardware acceptance remain separate tests on the destination systems.

DVMHost/FNE R06A00 or newer is recommended. This software is for personal,
non-commercial, amateur, and educational use and must not be used in
public-safety or life-safety-critical applications.
