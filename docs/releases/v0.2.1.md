# DVM Console 0.2.1

Released 2026-08-17. This patch release improves transmit security controls, talk-permit reliability, generated tone quality, recording storage, and channel-card interaction.

## Added

- Add built-in Ogg Opus encoding and playback for talkgroup audio recordings without requiring an external media process.
- Add the source radio ID to recording filenames so calls from different subscribers can be distinguished more easily.

## Changed

- Store new talkgroup audio recordings in Ogg Opus while retaining playback support for existing recordings.
- Show calls as Secure or Clear with compact algorithm labels and use a standard play control for recorded calls.
- Shorten the talk-permit indication while retaining startup and trailing silence to improve Bluetooth playback reliability.
- Send generated alerts, QCII pages, and DTMF through stable tone representations across supported digital voice modes.

## Fixed

- Ensure CLEAR transmissions do not use encryption and SECURE transmissions use the channel's configured algorithm and key.
- Keep microphone audio off the channel until the talk-permit indication and its output tail have completed.
- Preserve the active colors of SECURE, TX, PAGE, ALERT, and TAR controls while hovering or pressing.
- Keep the AGC target value visible beside its spinner controls.

## Packages

- `dvmconsole-0.2.1-osx-arm64.zip` — Apple Silicon macOS application bundle.
- `dvmconsole-0.2.1-osx-x64.zip` — Intel macOS application bundle.
- `dvmconsole-0.2.1-win-x64.zip` — Windows x64 package containing the self-contained `DvmConsole.exe`.

The packages are self-contained and do not require a separate .NET or Rust installation. Both macOS packages require macOS 14 or newer. All builds remain unsigned.

## Validation

The release source was validated with a complete Release build, 414 managed tests, and 14 native tests. The release workflow also verifies formatting, native architecture, macOS deployment requirements, Windows single-file packaging, and application startup on all three target runners.

## Safety and compatibility

DVMHost/FNE R06A00 or newer is recommended. NXDN 9600/EFR and P25 Phase 2 transport are not implemented. Test the release with a non-critical FNE and the intended audio hardware before operational use. This software is for personal, non-commercial, amateur, and educational use and must not be used in public-safety or life-safety-critical applications.
