# DVM Console 0.2.3

Released 2026-08-17. This patch release focuses on operator controls, busy-system receive stability, and a unified recording History workflow.

## Added

- Add zone-scoped `Enable all receive (zone)` and `Disable all receive (zone)` actions under Channels.
- Add optional global keyboard PTT selection, including F13 through F19, with a disabled state.
- Add receive activity bars for systems and zones, distinct system status colors, and visible center detents for channel volume and balance.
- Add recording search, filters, and catalog details to Event History.

## Changed

- Keep Recorder focused on TAR setup and channel recording configuration; completed recordings now converge into Event History.
- Reconcile recording metadata in cancellable background scans with bounded UI updates, stable legacy identities, and playback validation.
- Preserve call identity across concurrent streams, delayed packets, late packets, and independent output routes.
- Align Alert 1 and Alert 3 generation to the requested 1 kHz timing, digital-vocoder frame windows, and −25 dBFS level.

## Fixed

- Separate channel-card TX, PAGE, ALERT, and TAR interactions from card selection and stabilize enabled colors and hover rendering.
- Reduce duplicate and prematurely ended History calls, jerky busy-system playback, and silent recordings that contain valid audio.
- Preserve transmit and receive audio when disabling Keep mic warm.
- Improve codeplug/recent-path dialogs and identify the macOS menu bar application as DVM Console.

## Packages

- `dvmconsole-0.2.3-osx-arm64.zip` — Apple Silicon macOS application bundle.
- `dvmconsole-0.2.3-osx-x64.zip` — Intel macOS application bundle.
- `dvmconsole-0.2.3-win-x64.zip` — Windows x64 package containing the self-contained `DvmConsole.exe`.

## Validation

The release source passes 502 automated tests across Core, FNE, Vocoder, Audio, FNE Client, Media, and Desktop, and the Desktop project builds with no warnings or errors. Perform LaunchServices/headful smoke testing with the intended macOS package and live FNE/audio hardware before operational use.

## Safety and compatibility

DVMHost/FNE R06A00 or newer is recommended. NXDN 9600/EFR, P25 Phase 2 transport, and BER exposure remain outside this release. Test with a non-critical FNE and the intended audio hardware before operational use. This software is for personal, non-commercial, amateur, and educational use and must not be used in public-safety or life-safety-critical applications.
