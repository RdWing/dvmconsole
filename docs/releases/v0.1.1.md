# DVM Console 0.1.1

This patch release improves FNE transport compatibility and hardens the
Avalonia console's operator workflows. The refreshed 0.1.1 packages also
correct encrypted P25 receive audio and Console Settings scrolling.

## Highlights

- Support AES-256-ECB and AES-256-CBC transport framing, including automatic
  mode detection during FNE login. Existing encrypted codeplugs default to
  `transportEncryptionMode: auto`; deployments may explicitly select `ecb` or
  `cbc`.
- Fix encrypted login failures against FNE deployments using the legacy ECB
  transport framing.
- Preserve P25 encrypted receive state across each IMBE sequence so the
  configured algorithm and key are applied before vocoder playback.
- Keep the Debug Logs window modeless so it does not block interaction with the
  main console.
- Keep the final rows in every Console Settings tab fully scrollable above the
  status and Close footer.
- Improve codeplug/settings reload behavior by safely rebinding dependent
  view models and operator windows.
- Add regression coverage for transmit setup and rollback, patch forwarding,
  WAV silence trimming, FNE transport framing, and desktop window smoke paths.
- Add CI diagnostics and headful Avalonia window smoke coverage for the
  Windows build.

## Validation

The release was validated with the complete rebuild solution test suite, an
Apple Silicon package and window smoke test, and a live TYF FNE login using
both ECB and CBC transport paths. The tagged CI rebuild verifies and packages
Apple Silicon macOS, Intel macOS, and Windows x64. Packages remain
self-contained and unsigned; macOS packages require macOS 14 or newer.

## Safety and compatibility

DVMHost/FNE R06A00 or newer is recommended. Test the release with a
non-critical FNE and the intended audio hardware before operational use. This
software is for personal, non-commercial, amateur, and educational use and
must not be used in public-safety or life-safety-critical applications.
