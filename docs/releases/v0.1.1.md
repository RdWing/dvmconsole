# DVM Console 0.1.1

Released 2026-08-16. This patch release improves FNE transport compatibility and hardens the Avalonia console's operator workflows. The refreshed packages also correct encrypted P25 receive audio and Console Settings scrolling.

## Added

- Support AES-256-ECB and AES-256-CBC FNE transport framing, including automatic mode detection during login. Existing encrypted codeplugs default to `transportEncryptionMode: auto`; deployments may explicitly select `ecb` or `cbc`.
- Add regression coverage for transmit setup and rollback, patch forwarding, WAV silence trimming, FNE transport framing, and desktop window smoke paths.
- Add CI diagnostics and headful Avalonia window smoke coverage for the Windows build.

## Changed

- Keep the Debug Logs window modeless so operators can continue interacting with the main console while it is open.
- Rebind dependent view models and operator windows safely after codeplug or application settings reloads.
- Keep the final rows in every Console Settings tab scrollable above the status and Close footer.

## Fixed

- Restore encrypted login compatibility with FNE deployments that use legacy ECB transport framing.
- Preserve P25 encryption state across each IMBE sequence so encrypted receive audio uses the configured algorithm and key before vocoder playback.

## Validation

The release was validated with the complete rebuild solution test suite, an Apple Silicon package and window smoke test, and a live TYF FNE login using both ECB and CBC transport paths. The tagged CI rebuild verifies and packages Apple Silicon macOS, Intel macOS, and Windows x64. Packages remain self-contained and unsigned; macOS packages require macOS 14 or newer.

## Safety and compatibility

DVMHost/FNE R06A00 or newer is recommended. Test the release with a non-critical FNE and the intended audio hardware before operational use. This software is for personal, non-commercial, amateur, and educational use and must not be used in public-safety or life-safety-critical applications.
