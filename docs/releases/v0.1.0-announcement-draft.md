# Draft Release Announcement: DVM Console 0.1.0

DVM Console 0.1.0 is the first public release of the cross-platform Avalonia
desktop dispatch console for DVM systems.

This release provides self-contained downloads for Apple Silicon macOS, Intel
macOS, and Windows x64. Operators can monitor and transmit across multiple configured FNE
systems, mix simultaneous receive channels, route audio per resource, use
card/global/serial PTT, send alert and paging audio, manage patches and
multi-select groups, and review call history and recordings from one console.
Dense two-FNE codeplugs use indexed traffic routing, small-card audio meters stay
within their cards, connection pills show status-colored borders, and encryption
diagnostics can be dismissed after review.

The macOS build includes two microphone-processing choices: DVM Console
processing and Apple Voice Processing I/O with echo cancellation and automatic
gain control on compatible routes. The Windows package is now distributed as a
single managed EXE with only the native vocoder kept alongside it.

All packages are currently unsigned. Please follow the installation notes in
the release before launching, test with a non-critical FNE and the intended
audio hardware, and report reproducible issues through the project issue
tracker.

DVMHost/FNE R06A00 or newer is recommended. This software is for personal,
non-commercial, amateur, and educational use and must never be used in
public-safety or life-safety-critical applications.
