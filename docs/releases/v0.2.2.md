# DVM Console 0.2.2

Released 2026-08-17. This patch release improves simultaneous receive monitoring, adds per-channel stereo placement, and makes the Activity sidebar easier to focus during busy operation.

## Added

- Add a persistent stereo balance slider for every channel under Console Settings → Audio → Per-channel output routes.
- Route a channel fully left, fully right, or equally to both sides without boosting its configured output level.
- Add an Activity sidebar button that filters Event History to the channels in the current zone tab. Subscriber Command Audit remains system-wide.

## Changed

- Decode and queue receive traffic independently per channel so one delayed channel cannot block other active calls.
- Assemble and mix complete 20 ms PCM frames with bounded buffering at both the system-routing and channel-audio stages.
- Preserve the configured loudness of every channel during normal mixing. When the combined signal exceeds the signed 16-bit PCM range, apply one common scale to that 20 ms output frame only.
- Batch packet diagnostics and limit audio-meter updates so busy systems perform substantially less work on the UI thread.
- Refresh the recording catalog only when a recording actually closes instead of after every received packet.

## Fixed

- Prevent receive audio from becoming garbled or stuttery when several channel cards receive at the same time.
- Prevent sustained concurrent receive traffic from building unbounded work queues and making the application appear locked.
- Preserve P25, DMR, and NXDN call-lifecycle and encryption metadata when stale voice packets must be discarded from a full queue.
- Keep channels audible on a mono fallback device even when they have a left or right stereo balance saved.

## Packages

- `dvmconsole-0.2.2-osx-arm64.zip` — Apple Silicon macOS application bundle.
- `dvmconsole-0.2.2-osx-x64.zip` — Intel macOS application bundle.
- `dvmconsole-0.2.2-win-x64.zip` — Windows x64 package containing the self-contained `DvmConsole.exe`.

The packages are self-contained and do not require a separate .NET or Rust installation. Both macOS packages require macOS 14 or newer. All builds remain unsigned.

## Validation

The release source was validated with 429 managed tests, 14 native vocoder tests, an Apple Silicon package verification, and a LaunchServices window smoke test. The tagged CI workflow rebuilds and verifies Apple Silicon macOS, Intel macOS, and Windows x64 packages before publishing the release.

Concurrent decode, queue bounding, partial-frame assembly, stereo routing, mono fallback, encrypted control-frame preservation, and Activity filtering have automated regression coverage. Exercise the release with the intended output device and a realistic number of simultaneous live calls before operational use.

## Safety and compatibility

DVMHost/FNE R06A00 or newer is recommended. NXDN 9600/EFR and P25 Phase 2 transport are not implemented. Test the release with a non-critical FNE and the intended audio hardware before operational use. This software is for personal, non-commercial, amateur, and educational use and must not be used in public-safety or life-safety-critical applications.
