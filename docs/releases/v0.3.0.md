# DVM Console 0.3.0

Prepared 2026-08-19. This minor release makes the cross-platform Avalonia application the standalone DVM Console, removes the retired WPF implementation, and completes a maintainability-focused refactor of the operator interface without changing its established workflows.

## Added

- Add an ordered custom tone-pattern editor with reusable 300–2500 Hz tone and silence steps that remain within one transmitted call.
- Add macOS-only Console Settings actions for requesting Input Monitoring and microphone access again.

## Changed

- Split the main-window presentation logic into focused view models and services for audio settings, receive, transmit, tones, channel state, and recording metadata.
- Promote `dvmconsole.sln` to the repository root, move the live user guide under `docs/user-guide`, and make the `neo` branch the standalone application's integration line.
- Send P25 DTMF through the normal voice encoder and keep both Quick Call II tones within one frame-aligned call.
- Store TAR recordings at a 9 kbps Opus target while retaining VOIP mode and variable bitrate encoding.
- Embed TAR catalog metadata in Ogg Opus tags instead of creating adjacent JSON files. Existing Opus sidecars are migrated only after their embedded metadata is verified, without re-encoding audio.
- Restrict Avalonia developer diagnostics to Debug builds and exclude them from release packages.
- Consolidate build and packaging instructions in the live user guide and include the project and third-party license notices in every release package.

## Fixed

- Apply corrected P25 single-tone generation consistently to built-in alerts, the Tones panel, saved patterns, and Quick Call II.
- Wait for actual selected-microphone samples before playing the talk-permit cue so Bluetooth headsets can finish changing profiles.
- Prevent compact History date filters from overlapping and apply the neutral detent while a slider thumb is dragged with the mouse.
- Stabilize receiving channel cards by avoiding non-visual per-packet notifications and render the DMR and P25 level indicators at the same PCM-based cadence.

## Removed

- Remove the legacy Windows-only WPF project and its obsolete image, audio, and solution assets.
- Remove newly generated TAR JSON sidecars; Ogg Opus tags are now the recording's authoritative portable metadata.

## Packages

- `dvmconsole-0.3.0-osx-arm64.zip` — Apple Silicon macOS application bundle.
- `dvmconsole-0.3.0-osx-x64.zip` — Intel macOS application bundle.
- `dvmconsole-0.3.0-win-x64.zip` — Windows x64 package containing the self-contained `DvmConsole.exe`.

## Safety and compatibility

DVMHost/FNE R06A00 or newer is recommended. NXDN 9600/EFR and P25 Phase 2 transport remain outside this release. Test with a non-critical FNE and the intended audio hardware before operational use. This software is for personal, non-commercial, amateur, and educational use and must not be used in public-safety or life-safety-critical applications.
